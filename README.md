# Computer Fundamentals

一个面向**计算机小白、非科班创作者，以及想在 AI 时代真正做出东西的人**的交互式计算机基础知识网站。

> 目标不是让用户背术语，而是建立一张能支持 AI 协作开发的系统地图：知道一个概念为什么存在、内部怎么工作、会在哪里出错，以及它和其他层怎样连接。

## 在线网站

**Latest:** https://ai-ny8erj.v2.appdeploy.ai/

当前版本：V2 深度知识图谱。

## 网站现在能做什么

- **8 大知识体系 / 32 个关键节点**：硬件、操作系统、网络、编程、数据、Web、云与可靠性、AI 与大模型。
- **深度节点解释**：每个节点包含直觉解释、类比、历史/设计动机、内部机制步骤、AI 时代用途、排错视角、核心术语和跨节点连接。
- **机制实验室**：用交互模型理解二进制、CPU 指令周期、HTTP 请求链、数据库索引、LLM 推理。
- **知识图谱跳转**：从一个节点沿关联直接跳到另一个层级，而不是按课本章节线性学习。
- **AI 造物路径**：从“做网站 / 游戏 / AI 产品 / 自动化 / 数据工具”反推最该补的知识链。
- **术语图谱**：搜索术语时同时定位它属于哪一个系统层和关键节点。
- **继续深入**：提供 CS50x、Nand2Tetris、OSTEP、MDN、Pro Git、SQLBolt、Docker、Hugging Face 等后续资源。
- **响应式设计**：桌面和移动端都可以完成完整学习流程。

## 32 个关键节点

### 1. 硬件与计算
- 比特、字节与编码
- CPU、指令与时钟
- 内存、地址与缓存层级
- GPU 与并行计算

### 2. 操作系统
- 进程、线程与调度
- 虚拟内存与分页
- 文件系统与路径
- 权限、用户与隔离

### 3. 网络与互联网
- IP、路由与分组
- DNS：名字如何找到机器
- TCP、UDP 与可靠性
- HTTP、TLS 与一次请求

### 4. 编程与软件结构
- 变量、类型与数据结构
- 条件、循环与状态机
- 函数、模块与抽象边界
- 运行时、调用栈与错误

### 5. 数据与数据库
- 数据模型与 Schema
- SQL 与关系代数直觉
- 索引、事务与一致性
- 缓存与失效

### 6. Web 与应用
- 浏览器、HTML/CSS 与 DOM
- 前端状态与渲染
- 后端、API 与请求生命周期
- 身份认证、授权与密钥

### 7. 云、部署与可靠性
- 服务器、Linux 与进程环境
- 容器与镜像
- 构建、部署与 CI/CD
- 日志、指标与可观测性

### 8. AI 与大模型
- Token、Embedding 与表示
- Transformer 与注意力
- 训练、推理与概率生成
- RAG、工具调用与 Agent

## 内容结构

网站把知识内容放在 `src/knowledge.ts` 中。每个节点都有稳定的 `id` 和统一数据结构：

```ts
{
  id,
  domain,
  title,
  en,
  depth,
  summary,
  analogy,
  why,
  mechanism,
  aiUse,
  debug,
  terms,
  connects
}
```

这样后续扩展编译器、图形学、密码学、分布式系统、游戏引擎等领域时，只需要继续扩充知识图谱，而不需要重写页面结构。

## 内容原则

1. **先建立心智模型，再记术语。**
2. **解释“为什么存在”，而不只给定义。**
3. **同一个概念同时给机制视角和排错视角。**
4. **所有知识都要能连接到真实 AI 实作。**
5. **深入资料是下一层，不是开工前置作业。**

## 下一步计划

- 编译器与语言实现：源码 → AST → IR → 机器码
- 图形学与游戏引擎：帧循环、坐标、渲染管线、物理
- 密码学与 Web 安全：哈希、对称/非对称加密、签名、常见漏洞
- 分布式系统：副本、一致性、消息队列、故障模型
- AI 系统：KV Cache、量化、RAG 评估、Agent 可控性
- 为更多节点加入可操作动画与小型模拟器
