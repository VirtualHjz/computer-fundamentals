# Tests

## Test 1 - 深入浏览知识图谱并跨节点跳转 [sanity]
Viewport: desktop
Covers: 8 大领域导航, 32 关键节点, 深度解释, 跨节点连接
Description: 验证用户可以进入某个关键节点，阅读机制与排错视角，并沿知识连接跳到另一个领域。

Steps:
1. 滚动到“32 个关键节点”知识图谱，选择“网络与互联网”
2. 点击“HTTP、TLS 与一次请求”，阅读“内部到底发生了什么”和“排错时这样想”
3. 在“继续沿图谱跳转”中点击“后端、API 与请求生命周期”

Expected: 页面切换到 Web 与应用领域并展示“后端、API 与请求生命周期”的深度详情。

## Test 2 - 操作 HTTP 机制实验室
Viewport: desktop
Covers: 机制实验室, HTTP 请求分层动画, 可点击步骤
Description: 验证用户能通过交互实验理解一次 Web 请求依次经过 DNS、传输、TLS、HTTP、后端与浏览器。

Steps:
1. 滚动到“机制实验室”并选择“03 HTTP 请求”
2. 点击“TLS”步骤
3. 点击“继续请求”直到 Backend 步骤

Expected: 实验说明随步骤变化，并能看到 TLS 用于证书/密钥、Backend 用于身份/业务/数据库处理的解释。

## Test 3 - 切换数据库索引并比较查询代价
Viewport: desktop
Covers: 数据库索引交互实验, 性能机制可视化, guardrail against shallow definitions
Description: 验证用户可以直观看到全表扫描与索引定位在比较次数上的差异。

Steps:
1. 在机制实验室选择“04 数据库索引”
2. 观察未开启“使用索引”时的全表扫描
3. 开启“使用索引”

Expected: 说明从“全表扫描：12 次比较”切换到“B-Tree 直觉：3 次定位”，并展示更少的被检查行。
